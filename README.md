# College Club Events Website

A simple website to browse college club events and register for them, built with only HTML and CSS.

**Live demo:** https://your-username.github.io/club-events-website/

## Features

- Homepage with a banner and event cards
- Event details section for each event
- Registration form with built-in validation
- Responsive layout that works on phones and laptops

## Built with

- HTML
- CSS

## How to run

1. Download `index.html` and `style.css` into the same folder.
2. Double-click `index.html` to open it in your browser.
